# algorithms_and_data_structures лабы по алгоритамам
Содержимое репозитория:
BitovayaSort - Битовая сортировка.

Hash - Реализация хеш-таблицы.

HoareSort - Быстрая сортировка (схема разбиения Хоара).

Huffman_code - Алгоритм сжатия данных с помощью кода Хаффмана.

Piramida - Пирамидальная сортировка (сортировка кучей).

Shell - Сортировка Шелла.

boyer_moore_search - Поиск подстроки в строке алгоритмом Бойера-Мура.

sorting_on_4_files - Внешняя сортировка (с использованием 4 файлов).

topological_sort - Топологическая сортировка графа.

topological_sort_na_spiskax - Топологическая сортировка графа, реализованная на списках.

tsp_bruteforce - Решение задачи коммивояжера (TSP) методом полного перебора.
